llm-rag-finetuning-pipeline

本项目实现了一套面向垂直领域高精度逻辑推理的全栈工程化解决方案。在单卡 NVIDIA A100 (80GB) 的受限资源下，完成了从底层算子重构、精细化数据治理到大模型高效微调及混合 RAG 推理的完整闭环 。  

已完成核心功能
1. 底层算子级显存优化 (Triton-based Optimization)

    自主研发 Triton 算子：放弃了标准库方案，基于 OpenAI Triton 语言手写了专用的前向与反向传播函数（如 Fused Activation Entropy Loss） 。  

算力换空间策略：利用 LogSumExp 技巧重构了梯度计算流程，避免了全量概率矩阵在显存中的物理实例化，有效降低了 30%-50% 的训练显存占用 。  

2. “双轨分治”精细化数据工程 (Data Engineering)

    二元处理架构：创新性地将技术文档拆解为“微观细节”（性能参数、属性）与“宏观逻辑”（因果关系、技术演进）进行差异化提取 。  

指代消解与语义修复：建立了回溯补全机制，利用 Qwen-32B 对提取出的碎片化条目进行实体对齐与语境修复，确保了数据的语义独立性与检索价值 。  

结构化资产产出：实现了将非结构化文本向高保真 JSON 资产的自动化转化，为后续微调与 RAG 提供了标准化索引数据 。  

3. 混合思维链 (CoT) 模型微调 (Model Fine-tuning)

    Mixtral 8x7B 高效微调：采用 NF4 量化加载与 LoRA 技术，在单卡环境下完成了混合专家模型（MoE）的全量参数高效适配 。  

复合架构样本构建：构建了包含“结构化事实 (Input Fact) + 带噪上下文 (Retrieved Context) + 思维链问答 (QA Pair)”的三元复合训练样本，使模型习得“先定位证据、再推导结论”的逻辑范式 。  

4. 知识库构建与混合检索推理 (RAG System)

    父文档检索 (Parent Document Retrieval)：通过清洗后的 JSON 锚点建立索引，并在命中后自动回溯原始父文档上下文，保障了生成模型所需的语义完整性 。  

混合检索与分流：利用 BAAI/bge-m3 模型的表征能力，实现了针对参数指标的“特征检索”与针对机制分析的“语义检索”在统一向量空间内的隐式分流 。  

严格生成控制：基于 ChatML 协议构建 Prompt 模板，并配置自定义停止词逻辑，确保推理结果严格基于事实且逻辑可解释 。
